Reproducible example · Synthetic data

Try temporal pattern search

A small, reproducible example using synthetic daily observations. No clinical records or external services are required.

Input
35 synthetic daily observations
Window
7 observations
Runtime
Python standard library
Scope
Educational similarity search

What the example does

A seven-day query is compared with windows from a short synthetic series. Eligible windows are normalized and ranked by Euclidean distance. The example demonstrates data-quality handling and similarity retrieval with a few readable functions.

Run it locally

  1. Download and extract the example ZIP.
  2. Open a terminal in the extracted folder.
  3. Run the command below with Python 3.10 or newer.
python search_patterns.py

No third-party Python packages are required.

What to look for

The windows starting January 1 and January 15 have the same normalized shape despite different absolute values, so both have zero distance to the query. Constant windows and windows with two missing values are excluded.

How it differs from the research system

This educational example uses window-level normalization, a fixed query, and exhaustive search over a tiny synthetic dataset. It is not the published SMARTER pipeline, which uses site-level normalization and a larger extraction and retrieval workflow. The output is not a research result or performance benchmark.
