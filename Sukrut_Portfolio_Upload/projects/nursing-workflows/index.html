Clinical workflow research

Temporal patterns in nursing EHR activity

Representing local interaction patterns within a shift, alongside the broader temporal context.

Data
ICU nursing EHR audit logs
Representation
5-minute bins; 30-minute windows
Methods
Temporal features and clustering
Status
Exploratory research

The problem

Total EHR interaction counts do not describe when activity occurs. Brief bursts, quieter periods, and recurring sequences can disappear when an entire shift is summarized as one number.

My contribution

I prepared temporal representations of ICU nursing EHR interactions and used clustering and visual summaries to examine recurring activity patterns.

Units of analysis

Five-minute bin
A count of EHR interactions within one interval.
Thirty-minute window
Six consecutive bins representing a local activity pattern. Overlapping windows preserve changes within the shift.
Shift
The broader context in which those windows occur. Window counts and shift counts describe different quantities and should not be interchanged.

Research approach

  1. Prepare ordered, binned interaction sequences for each shift.
  2. Extract local windows and apply activity-based inclusion criteria.
  3. Cluster patterns and examine their temporal distribution.
  4. Interpret recurring behavior in the context of clinical workflows.

Interpretation

The work characterizes recorded system use. An EHR interaction pattern is not a complete measure of nursing workload, quality of care, or patient outcomes. This page does not report validated clinical predictions.

Patient-level records and operational EHR data are not distributed through this portfolio.
