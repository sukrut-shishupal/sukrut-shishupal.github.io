# Sukrut Shishupal — Research portfolio

Research Associate in Biomedical Informatics at the University of Utah.
Time-series machine learning, environmental exposure representations and research software.

**Live portfolio:** https://sukrut-shishupal.github.io/

## Selected work

- [Exposure library](https://sukrut-shishupal.github.io/projects/exposure-library/):
  Python extraction, HPC execution and a deployed Flask research application.
- [Nursing EHR patterns](https://sukrut-shishupal.github.io/projects/nursing-workflows/):
  within-shift temporal representations and exploratory clustering.
- [Pneumonitis exposure analysis](https://sukrut-shishupal.github.io/projects/pneumonitis/):
  geographic and temporal linkage of monitoring data to clinical timelines.
- [Runnable example](examples/temporal-search/README.md): synthetic temporal search.

The example is educational and separate from the published research pipeline.

## Preview locally

From the repository root:

```bash
python -m http.server 8000
```

Open http://localhost:8000. Plain HTML, CSS and JavaScript; no build step.
